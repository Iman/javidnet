
## نصب

```bash
git clone https://github.com/user/javid-net.git
cd javid-net/starlink-meshnetwork
pip install -r requirements.txt
```

تنها وابستگی اجباری: `cryptography` (برای Curve25519 + Ed25519). بقیه Python خالص یا اختیاری.

اختیاری: `Pillow>=10.0` برای تبدیل تصویر (WebP، تغییر اندازه). بدون Pillow، تصاویر فقط با gzip فشرده می‌شوند.

## استفاده

### کاربر عادی (LEAF)

```bash
python javidnet.py leaf --socks-port 1080
```

سپس برنامه‌ها را تنظیم کنید:

| برنامه | تنظیمات |
|--------|---------|
| Firefox | Settings > Network > Proxy > SOCKS5 `127.0.0.1:1080` |
| Chrome | `--proxy-server=socks5://127.0.0.1:1080` |
| Telegram | Settings > Data > Proxy > SOCKS5 `127.0.0.1:1080` |
| Signal | از پروکسی سیستم استفاده می‌کند |
| curl | `curl --proxy socks5h://127.0.0.1:1080 https://example.com` |

### رله (HOP)

کمک به گسترش برد مش. هر دستگاهی می‌تواند یک hop باشد:

```bash
python javidnet.py hop
```

### دروازه ماهواره‌ای (GATEWAY)

نیاز به دیش استارلینک. نقطه خروج اینترنت:

```bash
python javidnet.py gateway --cache-size 2000 --max-sessions 200
```

## معماری

![معماری سیستم](diagrams/png/01-architecture-System-Architecture.png)

سه نوع نود. کل سیستم همین است.

| نقش | کار | سخت‌افزار |
|-----|-----|----------|
| **LEAF** | کاربر نهایی. پروکسی SOCKS5 روی `127.0.0.1:1080` | هر گوشی/لپ‌تاپ |
| **HOP** | ترافیک را بین نودها رله می‌کند. برد مش را گسترش می‌دهد | هر دستگاه با Wi-Fi |
| **GATEWAY** | دیش استارلینک دارد. خروجی به اینترنت واقعی | RPi/رایانه + دیش استارلینک |

ترافیک LEAF در مش از دستگاهی به دستگاه دیگر پرش می‌کند تا به GATEWAY برسد، که آن را از طریق ماهواره به اینترنت ارسال می‌کند.

## مدل اعتماد

![زنجیره اعتماد](diagrams/png/03-trust-chain-Trust-Chain.png)

هیچ مرجع مرکزی وجود ندارد. اعتماد نفر به نفر منتقل میشه:

```
 اپراتور (دیش داره)
    |
    | حضوری تأیید می‌کنه
    v
 مورد اعتماد (میتونه بقیه رو تأیید کنه)
    |
    | حضوری تأیید می‌کنه
    v
 تأیید شده (میتونه از شبکه استفاده کنه)
    |
    x نمی‌تونه کسی رو تأیید کنه
```

**عضویت:** یه عضو فعلی رو ببین. QR کدت رو اسکن کنه. عضو شدی. بدون اپ‌استور، بدون پیامک، بدون ایمیل.

فرمت QR: `javidnet://<node_id>/<pubkey_hex>`

**ابطال آبشاری:** اگر عضوی لو بره، هر کسی که تایید کرده بود هم ابطال میشه.

داده اعتماد در SQLite (`~/.javidnet/trust.db`) ذخیره میشه با جداول: `peers`، `vouches`، `revocations`.

## بهینه‌سازی محتوا

![بهینه‌سازی محتوا](diagrams/png/04-optimization-Content-Optimization.png)

وقتی ۵ دیش استارلینک یک شهر را سرویس می‌دهد، هر بایت مهم است.

| حالت | چه چیزی عبور می‌کند | چه کسی بهره می‌برد |
|------|---------------------|-------------------|
| **بحران** | فقط متن. بدون تصویر، بدون JS، بدون ویدیو | ۲۵۰,۰۰۰ کاربر |
| **تنگ** | متن + تصاویر ریز (200px، کیفیت ۳۰٪). بدون JS | ۱۰,۰۰۰ کاربر |
| **عادی** | مرور فشرده. تصاویر در 800px | ۲,۰۰۰ کاربر |
| **سخاوتمند** | فشرده‌سازی سبک. تجربه تقریبا عادی | ۱,۰۰۰ کاربر |

کش محتوای دروازه (ایندکس SHA-256، تخلیه LRU، پیش‌فرض ۲ ترابایت) ضریب افزایش پهنای باند است. وقتی ۱۰,۰۰۰ نفر همان مقاله را می‌خواهند، فقط یک نسخه از لینک ماهواره‌ای عبور می‌کند.

## تاب‌آوری

![تاب‌آوری](diagrams/png/05-resilience-Resilience---Degradation.png)

| سطح | وضعیت | جاویدنت چکار می‌کنه |
|-----|-------|---------------------|
| **کامل** | ماهواره فعال | عملکرد عادی |
| **کاهش** | ماهواره قطع و وصل | صف + تلاش مجدد خودکار |
| **فقط مش** | بدون ماهواره | پیام‌رسانی محلی کار می‌کنه، اینترنت در صف |
| **دستی** | بدون مش | خروجی به USB، حمل فیزیکی به دروازه دیگر |

پیام‌ها هیچوقت گم نمیشن. توی صف پایدار (SQLite، `~/.javidnet/queue.db`) می‌مونن و وقتی ارتباط برگشت خودکار ارسال میشن.

**پاک‌سازی اضطراری:** اگر مشکوک به حمله فیزیکی بشید، یک دستور تمام داده‌های جاویدنت را نابود می‌کند (دایرکتوری `~/.javidnet/` حذف می‌شود).
